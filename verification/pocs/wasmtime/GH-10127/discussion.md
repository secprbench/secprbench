Winch: Fix Wasm vector loads to operate on 64-bits (#10127)



Preliminary source observation: A January 2025 Winch refactor derived 1, 2, or 4-byte access sizes for SIMD vector-extend loads that actually read 8 bytes. The PR says the correction restores bounds enforcement; its WAT disassembly tests use an out-of-bounds linear-memory address. Whether host bytes can be observed is still unproven.
Security impact, input reachability, earliest effective fix, and a three-revision oracle require independent review.
