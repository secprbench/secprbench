Fix a bug where arrays of GC refs were misreporting their count of GC edges (#10453)

* Fix a bug where arrays of GC refs were misreporting their count of GC edges

They were accidentally reporting the size of their GC reference elements, rather
than the count.

* fix miri ignore attr

Preliminary source observation: The March 17 DRC change stored array byte size as GC edge count. Its March 21 fix stores array length instead. Upstream test paints the heap with a poison value, then creates a guest GC-ref array and collects it; the test says the old behavior panicked while tracing past the GC heap.
Security impact, input reachability, earliest effective fix, and a three-revision oracle require independent review.
